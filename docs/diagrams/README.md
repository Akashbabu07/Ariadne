# Diagrams

Store source files (`.drawio`, `.mmd`, `.puml`) alongside exported images (`.svg`/`.png`) so diagrams stay editable.

Suggested first diagrams:
- `system-context.mmd` — services + external actors
- `service-dependency-graph.mmd` — which services call which
- `auth-flow.mmd` — sequence diagram for login/token flow

Mermaid is recommended since it renders directly in GitHub/most doc tools without extra plugins.
