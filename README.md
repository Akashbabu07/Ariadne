# ATLAS Documentation

This directory holds all project documentation, separate from code.

| Folder | Purpose |
|---|---|
| `architecture/` | System-level design docs: service boundaries, data flow, tech stack rationale |
| `adr/` | Architecture Decision Records — one file per significant technical decision |
| `api/` | API contracts/specs (OpenAPI, request-response examples) per service |
| `database/` | Schema docs, ER diagrams, migration notes per service |
| `diagrams/` | Source files and exports for diagrams (draw.io, mermaid, PlantUML, PNG/SVG) |
| `roadmap/` | Milestones, phase plans, backlog priorities |

Start with `architecture/overview.md` for a high-level picture of the system, then drill into the relevant subfolder.
